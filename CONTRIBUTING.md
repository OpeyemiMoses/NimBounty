# Contributing to NimBounty

Thank you for your interest in contributing to **NimBounty**! We welcome contributions from developers, designers, and web3 enthusiasts of all skill levels.

---

## 🚀 How to Contribute

### 1. Reporting Bugs
* Search existing [Issues](https://github.com/your-username/nimbounty/issues) to verify the bug hasn't already been reported.
* If not, open a new issue using our **Bug Report Template**.
* Provide detailed steps to reproduce, browser/device specs, and relevant console logs.

### 2. Proposing Features
* Open an issue using our **Feature Request Template**.
* Explain the problem your feature solves and why it benefits the NimBounty ecosystem.

### 3. Submitting Pull Requests

1. **Fork the Repository:** Create a personal fork on GitHub.
2. **Create a Feature Branch:**
   ```bash
   git checkout -b feature/amazing-new-feature
   ```
3. **Make & Test Your Changes:** Verify UI responsiveness, Nimiq Pay SDK compatibility, and ensure zero linter errors.
4. **Commit Your Changes:** Write clear, concise commit messages.
   ```bash
   git commit -m "feat: add real-time WebSocket alert for approved bounties"
   ```
5. **Push & Open PR:** Push to your fork and submit a Pull Request to `main`.

---

## 🎨 Style Guidelines

* **CSS / UI:** Follow our HatchAI design tokens defined in `style.css`. Use `Work Sans` for main headings, `Instrument Serif` for luxury italic accents, and `Geist Mono` for technical numbers/tags.
* **Icons:** Use clean inline SVG icons. Do NOT introduce raw emojis or sticker glyphs into task card templates.
* **JavaScript:** Write clean ES6+ JS without external heavy frameworks to keep the load footprint minimal for Nimiq Pay mobile WebViews.
* **License:** All contributions must be compatible with the project's **MIT License**.
