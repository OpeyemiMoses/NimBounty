# Contributing to NimBounty ⚡

Thank you for your interest in contributing to **NimBounty**! We welcome contributions from developers, designers, writers, and community testers.

---

## 🚀 How to Contribute

### 1. Reporting Bugs
Before opening a new issue, please search existing issues to ensure the bug hasn't been reported.
When filing a bug report, please include:
- A clear, descriptive title.
- Steps to reproduce the issue.
- Expected vs. actual behavior.
- Screenshots or console logs (if applicable).
- Device and browser information (e.g., Mobile Nimiq Pay Mini App, Desktop Chrome).

### 2. Suggesting Enhancements
Feature requests are appreciated! When submitting a feature request, please describe:
- The problem your feature solves or the user experience improvement it offers.
- Any design suggestions or mockups.

### 3. Pull Request Guidelines
1. **Fork the repository** and create your branch from `main`:
   ```bash
   git checkout -b feature/your-feature-name
   ```
2. **Follow existing code conventions**:
   - Keep JavaScript modular, explicit, and readable.
   - Respect light/dark mode variables in `style.css`.
   - Avoid external heavy npm frameworks unless discussed beforehand.
3. **Test your changes**:
   - Test UI responsiveness on both mobile and desktop screen sizes.
   - Verify Nimiq Pay SDK interaction fallbacks.
4. **Submit a Pull Request (PR)**:
   - Provide a clear PR title and summary of changes.
   - Reference any related issue numbers (e.g., `Fixes #12`).
